Eleven commits, two releases, v2.25.0 and v2.26.0.

Most of the day went on character death, which sounds morbid and is really a data-modelling problem.
A death is pinned to a scene, not to a character record, because the same character is alive earlier
in the manuscript. So it needed scene-pinned data shapes and pure derivations on top of them, a write
path with an undo and a confirmation, and then surfacing in the three places you'd want it — the
Writing Scene Guide, the Storyboard scene modal, and a read-only Character Status ledger in the
Analysis Hub. Deaths also reach the Markdown export now.

Three defects fixed in the mortality derivations before any of it shipped: empty-chapter ranking, a
drift value check, and stale overrides surviving longer than they should. Found them by testing the
pure functions, which is the argument for keeping them pure.

One more: the death ledger orphaned records when the write was retried. Retries are where
half-finished state hides.

Also released a scene guide you can actually open, an End Scene action, and a Write Scene button that
lands on the scene rather than near it. And pinned the mobile manuscript box above the keyboard
toolbar, because it was sitting underneath.

Twenty commits across four phases, ending at the first release gate, v2.10.0.

The main work was making dates real. A fantasy novel doesn't run on the Gregorian calendar, so I
added a WorldCalendar to the project with its own editor, a WorldDate type with an absolute-day sort
key, and dates on timeline events, scenes and characters. Then one shared date input component, so
every place you enter a date behaves identically.

Before this, ordering was whatever sequence things happened to be in. Now there's a real key to sort
by, which is what the timeline needed to stop lying.

Also replaced the Pulse quartet — four fields I'd added early and never liked — with a proper Systems
model: System as a seventeenth lore category, scene-level system invocations, an idempotent migration
off the old fields, and a Systems Ledger tab in the Analysis Hub.

Changed how I release, too. Per-phase releases became release gates — several phases land, then one
version. Cutting a release for every small phase was noise, and it made the changelog useless.

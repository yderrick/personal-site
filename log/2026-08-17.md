The longest day on this project. Four release gates, v2.11.0 through v2.15.0.

The Continuity Audit landed, with four checks that know when to shut up — a check that fires on every
scene gets ignored, so each one has conditions under which it stays quiet. Alongside it, dual
ordering, so the Storyboard reads in either narrative or chronological order.

Then progressions: how an entity changes over time, with a resolver to ask what something looked like
at a given point, and a stated rule for mixed indexing. That made the dead-character-speaking check
possible, which is exactly the kind of error you don't catch by rereading.

More in the same day — typed relationships and four layout modes for the Relation Graph, nested maps
and layers on the Lore Maps canvas, custom fields per lore category, three new categories, entity
templates, an unwritten-entity worklist, unlinked mentions, location mood boards, EPUB export,
read-aloud, chapter word-count targets, accessibility controls, Markdown and .docx import, and
project-wide restore checkpoints built on word-level snapshot diffs.

Two things I'd point at rather than the volume.

I ran a fix wave — a deliberate pass through review findings, rather than fixing things as I tripped
over them. The critical one: code was setting a key to undefined instead of omitting it, which
Firestore treats very differently from the local mock.

And I deleted Lore Maps entirely, three commits after building more of it that same day. Code, docs
and stray references. It was a feature I wanted rather than one the app needed, and keeping it would
have meant maintaining a second canvas forever. Also deleted the Character Dashboard, folding it into
Lore Explorer so there's one character editor instead of two that drift apart.

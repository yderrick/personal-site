Four density phases and a release, v2.19.0, then two fixes on top of it.

The mobile layout worked but wasted space — desktop spacing shrunk down, so you scrolled constantly.
Compressed the type scale and the chrome, went edge-to-edge on panes, tightened list density and
field boxes, and made the More sheet two columns.

Also shipped field labels and help text across the entire schema, which took yesterday's help
infrastructure and actually populated it.

Two fixes I want to remember:

- A missing Firestore index hid all reader feedback. Not an error — an empty list. The query
  succeeded and returned nothing, which looks exactly like nobody having left feedback.
- Mock Mode accepted undefined-valued fields that live Firestore rejects, so code passed locally and
  failed in production. Made the mock strict, so the two behave the same.

Added a component test harness alongside the existing unit tests — testing-library, four suites to
start.

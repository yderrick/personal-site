Thirty-seven commits, five lettered phases. The biggest single day I've had on this project.

Started with data integrity, because everything after it depends on that being sound. Added a Vitest
harness and the first pure-function test suites. Made Firebase initialisation failures degrade to
mock mode instead of half-dying in a state where some writes worked and some didn't. Reconciled the
character metadata with the schema it was supposedly validated against. And fixed JSON backups, which
turned out not to contain the whole project — a backup that silently omits things is worse than no
backup, because you only find out when you need it.

Then extracted four hooks out of ManuscriptWorkspace, which had become the file everything went into.
Deleted the AI Loom feature entirely.

The part I actually wanted to build came last: analysis. A Chekhov Ledger that pairs setups with
payoffs and tells you which ones you never resolved. Character arcs derived from the gap between what
a character wants and what they need. A rhythm strip showing scene and sequel alternation. Prose
diagnostics for echoes, filter words, adverbs and sensory balance. All wired into the Analysis Hub.

Also shipped a manuscript formatting pass — book typography, dialogue tools with curly quotes, export
to .docx and Markdown, autocorrect, Tidy, and Find and Replace.

Two bugs worth recording. The service worker only registered after sign-in, so a logged-out visit got
no offline shell at all. And Google sign-in looped back to the login screen inside the installed PWA
— the redirect handler sat on a different origin than the app, and modern browsers partition storage
across those.

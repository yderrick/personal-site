Started this site. The rule I set myself was that nothing gets designed until something is live at a
public URL, so the first deploy was an unstyled heading and one paragraph. It felt silly. It also
meant every decision after that was made against a real deployment instead of a localhost I was
hoping would translate.

The scaffold turned up something I'd have got wrong from memory: Astro is on 7 now, not 6. Most of
what I'd written down still held, but the compiler is Rust-based and no longer quietly fixes invalid
HTML, and Markdown goes through a different pipeline entirely. Reading the release notes took ten
minutes. Discovering it through a failing build would have taken longer and taught me less.

Wired `astro check` into the build script so type errors fail the build rather than shipping. Then I
broke it on purpose to confirm the gate actually holds — a check you haven't seen fail isn't a check,
it's a hope.

The design direction is amber on a warm near-black. Amber monochrome monitors were the alternative to
green phosphor and were picked because they were easier to read for hours at a stretch, which felt
like the right reference for something that's mostly a changelog. It also avoids the green-on-black
terminal look, which is the obvious move and therefore the boring one.

Everything is zero JavaScript so far, including the navigation. I'd like to keep it that way for as
long as the site lets me.
